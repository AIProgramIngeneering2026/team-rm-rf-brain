# Clip Forge

Сервис для автоматического поиска смешных и ярких моментов в записях стримов и формирования инструкций для нарезки вертикальных клипов (Shorts / Reels).

## Какую проблему решает

Стримеры и монтажёры тратят часы на просмотр многочасовых записей (VOD), чтобы найти моменты, которые зашли зрителям. 
Наш сервис решает эту проблему: он анализирует чат стрима (реакции зрителей), находит всплески активности, соответствующие смешным или важным моментам, и автоматически формирует JSON-манифест с таймкодами для нарезки клипов.

## Для кого этот сервис

- **Стримеры** — хотят быстро нарезать клипы из своих стримов для продвижения в соцсетях.
- **Монтажёры** — получают готовый план (таймкоды, кроп), чтобы не пересматривать запись целиком.
- **Владельцы пабликов** — ищут вирусные моменты для публикации в Telegram и Youtube.

## Границы системы

**Что входит в систему (In Scope):**
- Приём ссылки на запись стрима (VOD).
- Загрузка лога чата (время и сообщение) через внешний API.
- Анализ лога чата с помощью pandas (поиск эмодзи, ключевых слов, всплесков активности).
- Формирование JSON-манифеста: таймкоды отрезков, координаты кропа под 9:16.
- Отслеживание статуса задачи (Job) через API.
- Хранение заданий и результатов в базе данных.

**Что точно НЕ входит (Out of Scope):**
- **Рендеринг видео.** Сервис не скачивает видеофайлы и не нарезает их. Он выдаёт только текстовую инструкцию (JSON). Рендеринг — задача для FFmpeg или сторонних редакторов.
- **Загрузка видео на платформы.** Публикация готовых клипов в YouTube, Instagram или TikTok не реализуется.
- **Обучаемая ML-модель.** В рамках первой версии используется набор простых правил и эвристик (анализ слов и эмодзи), а не полноценная нейросеть. Шов для LLM предусмотрен на будущее.
- **Авторизация и биллинг.** В MVP нет полноценной системы логинов/паролей и платежей.

## Стек технологий

- **Язык:** Python 3.12
- **Работа с данными:** pandas (для обработки лога чата)
- **Веб-фреймворк:** FastAPI + Pydantic v2
- **База данных:** SQLite (на старте) → PostgreSQL (к концу семестра)
- **Инфраструктура:** Docker, docker-compose, Alembic (миграции)
- **Тестирование:** pytest
